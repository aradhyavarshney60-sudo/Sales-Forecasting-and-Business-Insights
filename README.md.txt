# Sales Forecasting and Business Insights

## Project Overview
This project analyzes the Sample Superstore dataset using Python. It explores sales, profit, regions, categories, and customer order patterns through simple data analysis and visualizations.

## Dataset
SampleSuperstore.csv

## Technologies Used
- Python
- Pandas
- Matplotlib

## Analysis Performed
- Data Loading
- Data Cleaning
- Missing Value Check
- Duplicate Removal
- Sales Distribution
- Sales by Category
- Sales by Region
- Top 10 States by Sales
- Profit by Category
- Sales vs Profit
- Orders by Ship Mode
- Discount vs Profit

## Conclusion
Technology category generated the highest profit.
The West region recorded the highest sales.
Higher discounts often resulted in lower profits.
Standard Class was the most frequently used shipping mode.
